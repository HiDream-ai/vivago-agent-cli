# VivagoAgent 插件品牌素材设计

## 背景

VivagoAgent 需要在 Codex 和 Claude Code 插件中展示统一品牌形象。设计交付包含一份
128×128 SVG 小图标、一份 512×512 浅色 SVG 和一份 512×512 深色 SVG。

## 已确认决策

- 完全保留设计稿原貌，不删除或替换背景。
- 浅色 Logo 保留白色方形背景。
- 深色 Logo 和 128 小图标保留黑色方形背景。
- SVG 作为可编辑源文件，另外导出相同尺寸和视觉效果的 sRGB PNG。
- 不重绘路径、不简化渐变、不添加文字，也不改变设计稿已有安全留白。

这项决定覆盖最初的透明背景建议。插件品牌规范必须明确标注这些素材为背景内置版本，研发不得在
未取得新设计稿的情况下自行移除背景。

## 文件和用途

素材统一放在插件根目录的 `plugin/assets/`，与 Codex 官方插件结构保持一致，并确保完整插件分发包携带：

| 文件 | 尺寸 | 用途 |
|---|---:|---|
| `vivago-agent-logo.svg` | 512×512 | 浅色界面标准 Logo，可编辑源文件 |
| `vivago-agent-logo.png` | 512×512 | 浅色界面标准 Logo 的栅格版本 |
| `vivago-agent-logo-dark.svg` | 512×512 | 深色界面 Logo，可编辑源文件 |
| `vivago-agent-logo-dark.png` | 512×512 | 深色界面 Logo 的栅格版本 |
| `vivago-agent-icon.svg` | 128×128 | 简化小图标，可编辑源文件 |
| `vivago-agent-icon.png` | 128×128 | 小尺寸栅格图标 |

Codex 插件清单设置 `composerIcon`、`logo` 和 `logoDark`，路径均相对于插件根目录；Skill 的
`agents/openai.yaml` 只保留品牌色，不重复声明插件级 Logo。Claude Code 当前插件清单不增加未经其
校验器支持的图标字段，但其安装包与 Codex 共用同一插件目录，因此仍会携带全部素材。

## 品牌色

- 主色：`#574DFF`，用于插件卡片、徽标和主要交互强调。
- 辅助紫：`#872FFF`，仅用于延续 Logo 渐变或较弱层级强调。
- 强调黄：`#FFCE00`，仅作少量点缀，不用于大面积正文背景。

Logo 内还包含蓝、粉、绿、红的径向渐变。界面元素不应逐一复刻这些渐变色；默认使用主色，完整渐变
只用于官方 Logo 图形。

## 验收

- 六份文件均包含在插件包内，SVG 和 PNG 尺寸、背景与设计稿一致。
- PNG 使用 sRGB，浅色版四角为白色，深色版和小图标四角为黑色。
- SVG 可解析且不引用外部字体、图片或网络资源。
- Codex 官方插件校验和 Claude Code 插件校验均通过。
- 分发组装测试确认品牌资产不会在生成 Marketplace 时丢失。

## 非目标

- 本次不制作透明背景版本。
- 不修改 Logo 图形、渐变、比例或安全留白。
- 不为 Claude Code 清单添加当前未支持的自定义字段。
- 不修改插件名称、产品定位或登录与业务协议。
