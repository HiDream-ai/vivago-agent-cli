# Security Policy

## Supported versions

The latest public Beta prerelease is the only supported Beta line. Personal development builds,
archived Pilot code, and older prereleases are not supported security release channels.

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability or include credentials, user content,
private service addresses, or exploit details in public discussions.

Use GitHub private vulnerability reporting:

https://github.com/HiDream-ai/vivago-agent-cli/security/advisories/new

Include the affected version, operating system, host (Codex or Claude Code), impact, and minimal
reproduction steps. Remove access tickets, refresh tokens, cookies, authorization headers,
presigned URLs, project identifiers, conversation identifiers, Turn identifiers, and customer
content before submitting evidence.

The maintainers will acknowledge the report through the private advisory and coordinate validation,
remediation, and disclosure there. Do not test against accounts, projects, or systems you do not own
or have explicit authorization to use.
