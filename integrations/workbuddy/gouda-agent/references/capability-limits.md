# 已知能力边界

当用户需求触及以下能力时，在提交前说明限制和补救方式，不能先承诺再静默省略。本文件随
Skill 版本维护，应以当前文件为准。

## 画面字幕不能稳定烧录

即使 brief 要求字幕，够搭 Agent 也不能稳定把字幕卡烧录到最终视频。用户明确需要字幕时：

1. 提交前说明字幕将在生成后由宿主补充。
2. brief 中仍逐句写出配音文案。
3. 交付后转录音轨获取时间点，再通过宿主可用的视频工具烧录字幕；9:16 视频需避开上下方
   平台 UI 安全区。

## 没有独立音效层

当前成片包含配音和背景音乐，但不会可靠合成撞击声、冰块碰撞等 Foley/效果音。需求依赖音效
时提前说明，并在交付后提供宿主侧混音方案。

## 不能选择具体 TTS 声音

当前不能通过 brief 精确选择声音、语速和音色。用户需要指定声音时，提交前说明限制；不得把
风格描述当成确定可控的声音选择器。

## 其他边界

需求超出远端能力且没有宿主侧补救时，在提交前明确说明。能力是否支持仍有不确定性时，把
不确定性写入提交前概括，并在交付阶段实际检查，不要仅凭 `RUN_FINISHED` 判断满足要求。
