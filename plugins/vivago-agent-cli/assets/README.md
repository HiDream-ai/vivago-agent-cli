# VivagoAgent brand assets

These files are the approved VivagoAgent artwork for Codex and Claude Code plugin distribution.
Use them as supplied; the backgrounds are intentional.

| Asset | Background | Intended use |
|---|---|---|
| `vivago-agent-logo.svg` / `.png` | White | Standard and light-interface Logo |
| `vivago-agent-logo-dark.svg` / `.png` | Black | Dark-interface Logo |
| `vivago-agent-icon.svg` / `.png` | Black | Compact icon at small sizes |

## Color

- Primary brand color: `#574DFF`.
- Supporting purple: `#872FFF`.
- Accent yellow: `#FFCE00`.
- The complete multicolor gradient belongs to the official Logo artwork. Product UI should use
  the primary color for normal accents instead of recreating the full gradient.

## Usage

- Preserve the square canvas, embedded white or black background, proportions, and existing safe
  area.
- Do not crop, recolor, add text, remove the background, or redraw the mark.
- Prefer SVG when the host supports it. Use the matching sRGB PNG where a raster asset is required.
- Do not substitute the standard Logo for the dark Logo by changing its background in code.
