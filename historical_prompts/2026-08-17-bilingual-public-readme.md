# 公开仓库中英文 README

## 背景

公开仓库当前只有中文 README。Vivago Agent CLI 面向海外正式环境发布，外部用户需要英文默认页，中文用户也需要保留完整说明。

## 用户需求

为公开仓库提供可以互相切换的英文和简体中文 README，两版都能独立说明安装、使用、安全限制和发布方式。

## 已接受决策

- `README.md` 作为英文默认页；
- `README.zh-CN.md` 作为简体中文页；
- 两个文件顶部提供明确的语言切换链接；
- 两版保持相同的章节、命令和产品边界；
- README 只写外部用户与公开贡献者需要的信息，不展示个人仓库或开发版分发入口。

## 明确非目标

- 不实现 GitHub Markdown 不支持的动态语言 Tab；
- 不引入文档站点或自动翻译服务；
- 不改变 CLI、插件、环境或发布行为。
